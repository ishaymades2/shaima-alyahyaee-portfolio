# Shaima Alyahyaee — Portfolio

A lightweight, responsive, bilingual portfolio built with plain HTML, CSS, and JavaScript. No build step or external JavaScript dependencies are required.

## Publish with Cloudflare Pages

1. In Cloudflare, open **Workers & Pages** and choose **Create application → Get started → Drag and drop your files**.
2. Upload this folder or its ZIP. Keep `index.html` at the top level of the uploaded assets.
3. Choose **Deploy site**. The site is static, so there is no build command.

## Publish with GitHub Pages

1. Create a GitHub repository and add every file in this folder to its root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)`, then save. GitHub will publish the source folder when changes are pushed.

## Contents

- `index.html` — bilingual portfolio page
- `styles.css` — responsive visual system and motion
- `script.js` — language toggle, project filters, gallery, and mobile menu
- `assets/` — portfolio previews, favicon, and résumé

Project previews were taken from the supplied portfolio PDF. Update the image or project details in `script.js` when you replace or add work.
